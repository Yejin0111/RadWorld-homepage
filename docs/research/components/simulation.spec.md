# Simulation comparison

Simulation follows Translation’s flat three-card comparison and Generation’s shared square image surfaces, captions and pill navigation. The paired images from Figure 5f remain unchanged: pre-TACE CT, RadWorld virtual post-TACE CT and acquired post-TACE CT, for two patients.

Each patient has one centered neutral Setting label and three centered treatment groups, with muted labels, brighter values and fine vertical separators instead of a filled box. Chemotherapy, Lipiodol and target artery are copied exactly from the prior page, with patient details switched together with all three images. Two clickable indicators and previous/next buttons use the existing carousel. No overlapping images or quantitative performance section is included.

The shared `.scan-comparison` caps each card at 330 px, keeps all three equal, and uses the same narrow-screen spacing as Translation. Treatment fields stack into readable rows on narrow screens.

Automatic cycling starts by default every five seconds, wraps back to the first example and continues after manual navigation with a fresh interval. There is no visible Auto-loop toggle. Offscreen, hidden-page and reduced-motion states pause cycling.

The shared centered story format now places the original treatment details in a native disclosure beneath the three scan cards. Image captions are centered. Opening details pauses case cycling for reading; original regimens and unwrapped drug lines are preserved.
